# Google Docs

Google Docs is an online word processor used to write and share documents. Its main advantage is that multiple people can work on the same file without passing separate copies around. Changes are saved automatically.

## Writing and formatting

A document can be organized using titles, headings and normal paragraphs. Headings are especially useful in long reports because they make navigation easier and can be used to build a table of contents. Google Docs also supports lists, images, tables, links, page settings and basic equations.

## Working with other people

The Share option allows the owner to invite people or share a link. Access can be limited to viewing, commenting or editing. These permissions matter: a viewer can read the document, whereas an editor can change its contents.

Comments are useful for asking questions or leaving feedback without rewriting the text. Suggesting mode lets someone propose edits that can be accepted or rejected. In a group assignment, one person can draft a section while others review it in the same document.

## Version history and exporting

Version history records earlier states of a document, so changes can be reviewed and a previous version restored if necessary. Specific versions can also be named. Documents can be downloaded in formats such as PDF or DOCX when a final copy is needed.
